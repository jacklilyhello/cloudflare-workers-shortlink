# 新系统需求与版本边界

当前迭代目标：2026-10-05 接续 PR #34 的既有测试系统，实现公共短码共享、自动数据维护及管理体验。本文取代旧文档中全 IP 测试放行、绝对禁止在线删除、仅手动迁移和日常手动导出的规定。交付证据在 PR 描述；未验收项不能以代码实现代替。

## 平台与保护边界

继续使用同一 GitHub 仓库、Cloudflare Worker `shortlink-new`、独立 D1 `shortlink-new-test` 和独立私有 R2 `shortlink-new-backups`。入口为 `test.gfw.mom`、新 Worker 自身 workers.dev 和后台 `link-admin.lily.lat`。实际 ID 与归属必须现场互证，不重复初始化或覆盖同名无关资源。

旧 Worker `short-link`、旧 LINKS KV、旧业务 Token、`gfw.mom` 生产指向及无关服务全部保留。六个历史文件逐字节保护。主账号 CF 浏览器严格只读，不代理扩充/轮换 Token；本机现有项目 CF 凭据仅固定只读核验。CF 基础设施与 D1 schema 写入仅经已授权 Actions，部署 Secret 留在 GH。测试/生产部署分别独立 workflow_dispatch，禁止 push、合并、定时部署；独立定时旧 KV 数据同步获授权但不部署。真实环境审批、OTP/MFA 不能绕过；生产发布与切流量另行授权。

## 一条映射，多域名前缀

D1 以大小写敏感短码全局唯一。一条映射供所有已登记、真实核验绑定且业务启用的公共域名解析；后来启用的新域名可直接访问已有短码。`domain` 保留为创建时返回前缀/来源元数据，不能限定解析命名空间。不复制每域映射、不恢复 URL 全局去重。匿名、管理员、业务 API 和旧迁移均适用；启停、到期、确认页、query 策略在所有前缀一致，访问事件按真实请求域名计数。

升级前备份并检查全局短码冲突。真实同码不同目标不能覆盖、合并或改码；保留原数据并单独报告。保留旧短码、原始完整 URL、审计、迁移和幂等数据。签名/重复 query、百分编码、fragment 保真，附加 query 规则详见 API 契约。

## 匿名前台

匿名免登录、不注册、不建立个人历史。保留长 URL、纯短码输入（无域名前缀，空值自动生成）、Turnstile、生成与复制。标题“长链接，轻一点。”，副标题明确一次生成、同短码可更换有效域名前缀。结果仅使用后端核验后的有效公共域名数组，完整地址可分别复制；不展示后台/停用/未绑定/无关域名。显著入口“获取新域名”指向 https://sink.lily.lat/link-fb。

精修玻璃效果、明暗/自动外观、键盘与触摸操作。真实浏览器 360px、390px、430px 和桌面检查输入、验证码、成功/失败/复制、多前缀、入口、长文本换行和溢出。后台只要求桌面。

## 管理员、域名与业务 API

Access 邮箱 OTP 只允许 `lilyyaloveyou@gmail.com`、`admin@888888.mom`。Worker 独立验证 RS256 JWT 的签名、issuer、AUD、有效期、type、邮箱；所有写接口校验准确 Origin/CSRF。公共域名及 workers.dev 不提供后台/机器 API。

域名流程：后台登记→管理员本人在 Worker 面板手动绑定 `shortlink-new`→后台刷新真实核验→业务启用。官方 CF Custom Domain 记录必须属于固定账户和正确 Worker/default service 环境，并结合 Worker 所有权/DB/R2及 HTTPS 服务核验；DNS或网站能打开不能替代绑定证据。独立最小只读凭据不等于 GH 部署 Token，资格失败如实显示。状态包括未绑定、绑定中、已核验、核验失败；最后尝试与最后成功时间分开。后台不创建/删除/转绑 DNS 或 Custom Domain。

停用只改变 D1 业务状态，保留 CF 绑定/全局映射；请求显示“该短链域名已停用”，不能创建或跳转。其他有效域正常。重新启用须确认绑定仍有效。`test.gfw.lat` 等待管理员本人绑定，agent 不代操作。

机器接口固定 `POST https://link-admin.lily.lat/api/shorten`，Bearer 业务 Token，只能创建，字段 `url/domain/slug?`。domain 选择返回前缀，须登记、核验、启用且该 Token 获准使用；不返回其他前缀、不获得管理能力。CF 精确接口仅允许 `87.83.110.180`：互补名单外 Block 在 Skip 前，Skip 保留必要参数，无 IPv6放行；保留精确 Custom Errors JSON例外。IP 不进入后台、D1、Token或应用变量；普通部署不能恢复全IP或覆盖后续面板名单。

## 启停与彻底删除

链接每行快捷启停只改变 enabled，不修改 expires_at。停用/过期仍占用短码，所有公共前缀一致生效。彻底删除须展示短码、目标及所有前缀失效范围、默认取消，管理员明确确认后执行受保护 DELETE。删除在线可解析映射，仅保留必要无 URL 的短码占用/幂等标记与审计；原短码不复用，迁移、重试和旧幂等不能复活。不修改旧 KV，历史备份按原策略保留，不能声称全历史抹除。真实验收只用本轮一次性数据。

## 自动备份与旧 KV 增量

按设置周期生成 D1 单事务 staging 一致性快照，经任务互斥、分页/分片推进、断点和有限退避自动存入私有 R2。完成前校验真实 R2对象、大小、记录数与内容摘要；校验失败不得更新上次成功。后台主要设置开关/间隔/保留期并查看开始/完成/上次成功/下次预计、大小/行数/耗时/失败/重试；移除日常手动导出、下载和立即执行。受保护内部验证工具可以保留。升级后快照覆盖删除占用和自动计划状态，需恢复完整性验证。

独立定时 Actions 每30分钟检查后台设置，默认24小时开始增量重扫，每次有限页数、互斥、幂等并恢复未完成 run。旧 KV永远GET只读，固定新D1唯一写入目标，不部署。管理员可暂停；现存映射只比对不覆盖编辑、停用、到期或删除。异常保留分类，权限/资源/网络故障不得伪装跳过。KV游标扫描不是原子快照，历史696/18计数不是当前实测结果。真正冲突集中说明，非冲突工作继续。

## 统计、时间及保留

近似访问事件（可能含重复/机器人），异步 D1按真实域名、国家、设备、来源hostname日聚合，不保存原始IP/UA/来源路径、不拖慢跳转。用真实统计绘制世界地图、趋势和排行，有范围、图例、悬停、加载/空态和未知地区；禁止假热点。静态地图可随项目部署，不复制 Sink源码或引入不必要数据服务。

时间默认完整 Asia/Singapore（UTC+8），创建/发生/开始/完成/上次成功语义明确。历史只有UTC日期的聚合不能准确重分桶，趋势如实标为UTC自然日，其余时间固定新加坡。访问聚合、审计、备份保留天数允许0=永久；分别说明按访问聚合UTC日期、审计发生时间、备份成功完成时间计算。间隔和限流保持各自正数范围，不将0机械套用。

## 面板名称与验收

经独立 Actions对确认归属的三 Access应用和项目 WAF规则改为简洁正常用途名称。只改可编辑name/description，稳定ID/ref/私有checkpoint保留所有权；AUD、域名路径、策略邮箱、会话、动作参数、规则相对顺序不因改名变化。IP收紧是独立变更，共享CustomErrors名称不改；后续部署兼容内部身份且不恢复长串显示。

完成流程持续为开发→本地 check→修复→PR/CI→规则允许合并→主动dispatch测试部署→真实验收。实际管理员第二域名绑定、OTP、指定IP出口、独立只读凭据等依赖待其他可推进工作完成后集中说明。长期保留与云端恢复未执行时明确列出，不能假称通过。
